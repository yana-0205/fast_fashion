# Reproduction Scope

## Preserved intent

- Attribute-driven womenswear concept creation
- Image generation or selection
- Multimodal demand forecasting for the next ten weeks
- Color, material, season, and price analysis
- Design storage, filtering, and comparison

## Redesigned

- User journey and information architecture
- Frontend component structure
- Backend API contracts
- Model service boundary
- Error handling and offline fallback
- Testing and reproducibility workflow

## Deferred from V1

- Login and registration
- User, company, dataset, and model administration
- Full 2D-to-3D Meshy workflow
- Full restoration of every historical screen
- Claims of reproducing original metrics before independently validating them

## Evidence policy

The portfolio will label implemented, deferred, and experimental behavior separately. A statistical shortcut must not replace the trained forecasting artifact in the product runtime.
